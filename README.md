# MultiplicationPourYoussef

Un petit jeu web en français pour aider un enfant à apprendre les tables de multiplication de 1 à 10 en s'amusant.

## Fonctionnalités

- Questions aléatoires sur toutes les tables ou sur une table choisie.
- Score et série de bonnes réponses pour encourager la progression.
- Messages positifs, emoji et ambiance colorée adaptée aux enfants.
- Interface simple utilisable dans un navigateur, sans installation.

## Lancer le jeu

Ouvrez simplement `index.html` dans un navigateur web.
